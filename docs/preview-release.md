Workbench is available as an Apple Silicon developer preview. It includes source-backed research, isolated Git reviews, durable Activity, read-only inbox triage, and optional local or Daytona desktops.

The downloadable Mac build is ad-hoc signed and unnotarized. Use the [source setup](https://github.com/wstria/workbench/blob/main/README.md#start-on-macos) for a local build. See the [verification report](https://github.com/wstria/workbench/blob/main/docs/release-verification.md) for fixture coverage and release limits.
